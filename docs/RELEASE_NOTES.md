# Release Notes

## 0.1.0

- Added the initial TypeScript CLI with `check`, `fix`, `explain`, and `doctor` commands.
- Added deterministic package checks for JSON validity, dependency sections, metadata, scripts, package-manager lockfiles, module-system risks, and publishing metadata.
- Added safe fix preview and `--write` behavior.
- Added human-readable and JSON output modes.
- Added fixtures, Vitest coverage, README usage examples, and GitHub Actions CI.
